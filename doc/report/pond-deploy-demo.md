## ขอบเขตและข้อจำกัด

เดโมใหม่นี้ตรวจ happy path หนึ่งรอบและ UI ภาษาไทย ไม่ใช่ load/concurrency test และไม่ครอบคลุมทุก role/endpoint
Start ได้ก่อนเวลาเริ่มที่จองไว้ ยังเป็นข้อจำกัดที่เห็นจริงในรอบนี้
ชำระก่อน start ตามลำดับเดโม จึงไม่ได้พิสูจน์ว่าระบบบังคับชำระก่อนเริ่ม
เวลาในหน้าเว็บไม่มี timezone จึงรายงานตามค่าที่กรอกและเห็นใน UI ไม่อ้างว่าเป็นเวลาไทย
ข้อความแจ้งเตือน lifecycle ยังมี enum ภาษาอังกฤษ แม้ badge ของรอบ/เครื่องเปลี่ยนเป็นภาษาไทยแล้ว
badge “ส่งรายการชำระเงินแล้ว” หมายถึงมีรายการ payment ไม่รับรอง PAID ทุกวิธี; รอบนี้ยืนยัน PAID จากหน้ารายละเอียด QR จำลอง

เดโมก่อนเปลี่ยน UI ใช้ Session 1/Payment 1 และเคยเห็นปุ่มชำระเงินหลังจ่าย ข้อนี้แก้แล้วและตรวจซ้ำใน UI ชุดล่าสุด
หลักฐาน API จากเดโมก่อนหน้า: GET /api/v1/sessions/1 ได้ COMPLETED, finish ซ้ำได้ 400 JSON และ anonymous GET machines ได้ 401
ไม่ได้รัน API negative cases เหล่านี้ซ้ำในรอบ UI ใหม่ ดูประเด็น contract ที่ยังรอตกลงใน pond-contract-check.md

## การสาธิตซ้ำ

login → จองเครื่องว่าง → เลือกเวลาข้างหน้าที่ไม่ซ้อน/30 นาที → ประวัติ → ชำระ QR จำลอง
→ กลับประวัติและตรวจปุ่มชำระเงินหาย → เริ่มใช้ → จบรอบ → เปิดรายละเอียดเครื่องและแจ้งเตือน
ใช้เลขรอบที่เพิ่งสร้างเท่านั้น ถ้าเครื่องไม่ว่างให้เลือกเครื่องพร้อมใช้อีกเครื่อง
