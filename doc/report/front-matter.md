## บทคัดย่อ

โครงงานนี้พัฒนา LaundryHub ระบบจัดการร้านซักรีดที่รองรับบริการสองรูปแบบในระบบเดียว ได้แก่ บริการฝากซัก (Full-Service) ที่คิดราคาจากน้ำหนักและประเภทบริการ และบริการซักผ้าหยอดเหรียญ (Self-Service) ที่ลูกค้าจองและใช้เครื่องเอง คิดราคาจากเวลาที่ใช้ ผู้ใช้ระบบมีสามบทบาท คือลูกค้า พนักงาน และผู้ดูแลระบบ

ระบบพัฒนาด้วย Spring Boot 3.5.7 และ Java 17 ตามสถาปัตยกรรมแบบชั้น (Layered Architecture) แยก Controller, Service, Repository และ Domain อย่างชัดเจน ใช้ PostgreSQL 16 พร้อม Flyway สำหรับจัดการ schema ใช้ Spring Security กำหนดสิทธิ์สามบทบาท และเปิดเผยบริการผ่าน REST API พร้อมเอกสาร Swagger/OpenAPI ส่วนการแสดงผลหน้าเว็บใช้ Thymeleaf *(ตรวจขอบเขตหน้าเว็บที่ทำเสร็จจริงก่อนส่ง)*

การออกแบบประยุกต์หลัก SOLID และ Design Pattern ที่มีเหตุผลรองรับ ได้แก่ Strategy (การคิดราคา และวิธีชำระเงิน), State (สถานะออเดอร์และเครื่อง), Observer (การแจ้งเตือน), Factory และ Facade (การชำระเงิน) รวมถึงรูปแบบเชิงสถาปัตยกรรม Repository, Service Layer, DTO และ Dependency Injection แบบ constructor ฐานข้อมูลมี 10 ตาราง ครอบคลุมความสัมพันธ์แบบ One-to-One และ One-to-Many

ผลการทดสอบ ชุดเทสต์อัตโนมัติรอบเต็มรัน 369 ข้อ ผ่านทั้งหมด (ผ่าน 333 และข้าม 36 ข้อที่ต้องเปิดฐานข้อมูลเอง) และเมื่อเปิดเทสต์ที่ต่อ PostgreSQL จริงรันครบ 379 ข้อ ผ่านทั้งหมด *(ตรวจตัวเลขกับ doc/test-report/test-report.md และรันซ้ำก่อนส่ง)* ระบบถูก deploy ใช้งานจริงบน Render และ Neon *(ตรวจ URL และสถานะก่อนส่ง)* การพัฒนาใช้ Git workflow แบบแตกกิ่งส่วนตัวและรวมผ่าน Pull Request พร้อมการรีวิวโค้ดโดยเพื่อนร่วมทีม ซึ่งช่วยตรวจพบข้อบกพร่องหลายรายการก่อนรวมงาน

## คำนำ

รายงานโครงงานฉบับนี้จัดทำขึ้นเป็นส่วนหนึ่งของการศึกษาวิชา CP353002 หลักการพัฒนาซอฟต์แวร์ (Principles of Software Development) โดยมีวัตถุประสงค์เพื่อนำเสนอการออกแบบและพัฒนาระบบ LaundryHub ซึ่งเป็นระบบจัดการร้านซักรีดที่รวมบริการฝากซักและซักผ้าหยอดเหรียญไว้ในระบบเดียว ตามหลักการออกแบบซอฟต์แวร์เชิงวัตถุ หลัก SOLID และ Design Pattern

เนื้อหาในรายงานแบ่งเป็น 5 บท ได้แก่ บทที่ 1 บทนำ บทที่ 2 ทฤษฎีและเทคโนโลยีที่เกี่ยวข้อง บทที่ 3 วิธีดำเนินการและการออกแบบระบบ บทที่ 4 ผลการพัฒนาและการทดสอบ และบทที่ 5 สรุปผล อภิปรายผล และข้อเสนอแนะ โดยสมาชิกแต่ละคนรับผิดชอบเขียนส่วนที่ตรงกับโมดูลของตนเอง และรวมเป็นเล่มเดียว

ผู้จัดทำขอขอบพระคุณอาจารย์ประจำวิชา รศ. ดร.ปัญญาพล หอระตะ ที่ให้ความรู้และคำแนะนำตลอดการทำโครงงาน และขอบคุณสมาชิกทุกคนที่ร่วมกันพัฒนาและตรวจทานงานจนแล้วเสร็จ หากรายงานฉบับนี้มีข้อบกพร่องประการใด คณะผู้จัดทำขออภัยมา ณ ที่นี้ด้วย
