## รูปแบบไฟล์ (สั้นๆ)
```
## บทที่ 3 วิธีดำเนินการและการออกแบบระบบ      <- เริ่มส่วนของบทที่ 3 (เขียนเฉพาะบทที่ตัวเองรับผิดชอบ)

### การออกแบบฐานข้อมูล                          <- หัวข้อหลัก ไม่ต้องใส่เลข ระบบใส่ 3.1, 3.2 ให้เอง
ข้อความธรรมดา ย่อหน้าละบรรทัด

#### หัวข้อย่อย                                  <- ได้เลข 3.2.1 ให้เอง
- รายการแบบจุด            1. รายการแบบตัวเลข
| คอลัมน์ | คอลัมน์ |     <- ตารางแบบ Markdown
|---|---|
| ข้อมูล | ข้อมูล |
![คำบรรยายภาพ](../../img/ชื่อไฟล์.png)        <- ภาพ (ระบบใส่ "ภาพที่ N" ให้เอง)

## เอกสารอ้างอิง                                <- รวมจากทุกคน ตัดซ้ำ เรียงตัวอักษรให้เอง
- ผู้แต่ง. (ปี). ชื่อเรื่อง. สำนักพิมพ์.
## ภาคผนวก                                      <- ภาคผนวกของตัวเอง
```
- **หัวข้อ `###` ชื่อเดียวกันจากหลายคนในบทเดียวกัน** จะถูกรวมไว้ใต้หัวข้อเดียวกัน (เช่น "การออกแบบฐานข้อมูล" ของโอ๊คและโชกุน) และมีป้าย "ส่วนของ…" นำหน้า
- บรรทัดที่ขึ้นต้นด้วย `>` และ `---` ไม่แสดงในเล่ม (ใช้เขียนโน้ตถึงตัวเอง)
- ข้อความที่ต้องตรวจก่อนส่ง ให้ใส่ในรูปแบบ `*( ... )*` จะถูกไฮไลต์เหลืองในไฟล์ Word
- **ห้ามเขียนสิ่งที่ยังไม่ได้ทำ** อ้างเฉพาะสิ่งที่มีอยู่จริงในโค้ดหรือเอกสาร อาจารย์จะตรวจเทียบ
